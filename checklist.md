# First-Response Checklist

- [ ] Acknowledge the page within 5 minutes
- [ ] Join the incident bridge
- [ ] Announce you are on-call lead
- [ ] Identify affected service(s) and current impact
- [ ] Check the Actions tab for stuck runs burning runner minutes
- [ ] Cancel any runaway CI jobs
- [ ] Post status update to the on-call channel
- [ ] Escalate if not contained in 15 minutes
- [ ] Capture timeline notes for the post-incident review
- [ ] Schedule the debrief
